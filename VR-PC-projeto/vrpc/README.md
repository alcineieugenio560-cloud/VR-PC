# VR PC (Cardboard / VR Box)

1. Crie um repositório no GitHub e envie todo o conteúdo desta pasta (branch main).
2. Aba **Actions** > "Build APK" (roda sozinho no push, ou clique em *Run workflow*).
3. Ao terminar, baixe o artefato **VR-PC-apk** > instale o `app-debug.apk`.

Uso: coloque o celular no VR Box (paisagem). Mostre as duas mãos abertas à câmera ->
teclado + tela aparecem. Olhe para um item por 1s (ou toque na tela) para clicar.
Se a cabeça girar ao contrário: Config. > Inverter giro horizontal/vertical.
